Antes de empezar

Requisitos de la práctica

  • Python 3.13 o superior para ejecutar el agente y sus herramientas.
  • uv para crear el entorno del proyecto, instalar dependencias y correr scripts.
  • Terminal básica para instalar dependencias, cambiar de rama y correr el proyecto.
  • Git y GitHub para recorrer los pasos incrementales del tutorial.
  • Ollama para ejecutar un modelo local sin depender de una API externa.

La idea no es aprender todo Python desde cero: vamos a usarlo como vehículo para entender agentes, prompts, herramientas y memoria.

Setup

OOllama

Qué es Ollama

Ollama es una herramienta para ejecutar modelos de IA desde tu computadora. En esta práctica lo usamos como el motor local que responde las consultas del agente construido en Python.

Descarga

Baja modelos y los guarda localmente para poder usarlos sin depender de una API externa.

Ejecuta

Permite iniciar un chat con un modelo desde CMD, PowerShell o Terminal.

Conecta

Expone un servidor local para que nuestro script Python pueda enviar prompts y recibir respuestas.

Concepto base

Modelo vs. agente

Modelo

Genera texto a partir de una consigna. Puede sugerir ideas, pero no sabe consultar nuestro catálogo por sí solo.

Agente

Usa el modelo para decidir pasos: preguntar faltantes, llamar herramientas, leer resultados y responder con criterio.

Razonamiento operativo

El rol de las herramientas

Un agente de cocina mejora cuando no inventa recetas: consulta datos, filtra opciones y explica por qué una recomendación encaja.

Observar

Lee ingredientes, tiempo, equipamiento, dieta y nivel de dificultad.

Decidir

Define si necesita buscar recetas, validar restricciones o pedir más datos.

Actuar

Ejecuta herramientas y compone una recomendación clara, accionable y segura.

Arquitectura

Agent loop

El ciclo del agente se repite hasta que tiene suficiente información para recomendar un plato.

Código

Agent loop en Python

def recomendar_cocina(agente, pregunta): respuesta = agente(pregunta) # El SDK se encarga del loop interno: # 1. interpreta la consulta # 2. decide si usa herramientas # 3. incorpora resultados # 4. genera la respuesta final return respuesta

La implementación real puede ser corta porque el framework encapsula buena parte del ciclo.

Paso 2

System prompt

El agente recibe instrucciones de rol, alcance y criterios de respuesta.

SYSTEM_PROMPT = """ Sos un asistente de cocina práctico y cuidadoso. Objetivo: - recomendar platos posibles con los ingredientes disponibles - adaptar la respuesta a tiempo, dieta y dificultad - explicar pasos concretos sin inventar datos del catálogo Si la consulta no es de cocina, respondé brevemente que solo podés ayudar con comidas, recetas e ingredientes. """

Paso 2

Guardrails en acción

Las instrucciones reducen respuestas fuera de tema y sostienen el objetivo del asistente.

consulta = "¿Qué notebook compro?" respuesta_esperada = """ Puedo ayudarte con cocina, recetas, ingredientes y planificación de comidas. Si querés, contame qué tenés en casa y te propongo una opción. """

Paso 3

Conectar datos con @tool

La herramienta permite que el agente consulte recetas en vez de inventarlas.

from strands import tool import json @tool def buscar_recetas(ingredientes: list[str], tiempo_max: int = 45): with open("data/recetas.json", encoding="utf-8") as archivo: recetas = json.load(archivo) return [ receta for receta in recetas if receta["tiempo_minutos"] <= tiempo_max and set(ingredientes).intersection(receta["ingredientes"]) ]
git checkout feature/03-herramientas

Paso 3

Consulta a datos reales

pregunta = """ Tengo arroz, huevo y zanahoria. Quiero algo rápido y vegetariano. """ resultado_tool = buscar_recetas( ingredientes=["arroz", "huevo", "zanahoria"], tiempo_max=30, ) # El agente usa este resultado como evidencia # para recomendar una receta concreta.

El modelo redacta la respuesta, pero la selección sale de datos consultables.

Múltiples herramientas

git checkout feature/04-varias-tools

Paso 4

Selección de herramienta

consulta = """ Tengo garbanzos y espinaca. No consumo lácteos y tengo 30 minutos. """ # Posible ruta del agente: # 1. buscar_recetas(["garbanzos", "espinaca"], 30) # 2. validar_restricciones(receta, ["sin lacteos"]) # 3. responder con receta, pasos y ajustes

La selección de herramienta depende de la intención de la consulta, no de una regla fija.

Paso 5

Memoria y sesiones

Se agrega persistencia para recordar preferencias entre interacciones.

from strands.session.file_session_manager import FileSessionManager session_manager = FileSessionManager( session_id="cocina-demo", storage_dir="sessions", ) agente = Agent( model=modelo, system_prompt=SYSTEM_PROMPT, tools=[buscar_recetas], session_manager=session_manager, )
git checkout feature/05-memoria

Paso 5

Persistencia de mensajes

agente("Soy vegetariana y prefiero comidas rápidas.") agente("Tengo lentejas y tomate. ¿Qué hago?") # La segunda respuesta puede usar el dato anterior: # vegetariana + comidas rápidas.

La memoria evita repetir preferencias en cada mensaje y mejora la continuidad de la conversación.

Paso 6

Loop interactivo

El agente queda disponible para una conversación continua desde la terminal.

while True: consulta = input("Cocina > ").strip() if consulta.lower() in {"salir", "exit", "q"}: break print("Agente: ", end="", flush=True) agente(consulta) print()
git checkout feature/06-loop

Paso 6

Conversación continua

Cocina > Tengo pollo, zapallo y arroz. Agente > Podés hacer un arroz cremoso con pollo y zapallo... Cocina > Que sea sin horno. Agente > Perfecto: lo resolvemos en una olla o sartén profunda... Cocina > Armame la lista de compras para mejorarla. Agente > Te conviene sumar cebolla, caldo y perejil...

El valor aparece cuando la conversación acumula contexto y el agente adapta la recomendación.

Cambiar de modelo

from strands import Agent def crear_agente(modelo): return Agent( model=modelo, system_prompt=SYSTEM_PROMPT, tools=[buscar_recetas, validar_restricciones], ) agente = crear_agente(modelo_en_la_nube)

Validación con otro modelo

casos = [ "Tengo tofu y arroz. Quiero algo sin gluten.", "Necesito cena para 4 personas en 25 minutos.", "No tengo horno. ¿Qué receta conviene?" ] for caso in casos: print("Consulta:", caso) agente(caso)
